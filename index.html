Personal project

Travel AI Assistant

I wanted to learn what happens after the LLM call: API design, conversation state, persistence and reliability.

It uses Java 21, Spring Boot, LangChain4j, Ollama with Qwen, PostgreSQL and React/Vite. The application exposes a REST chat API, keeps conversations isolated with a conversation ID, and stores chat history in PostgreSQL so the assistant can remember context across messages.

It is a hands-on way for me to learn LLM integration, prompt handling, conversation memory and the practical trade-offs around AI in backend systems.
