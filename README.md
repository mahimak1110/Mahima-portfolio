# Mahima Personal Portfolio

A simple static portfolio for Kumari Mahima.

## Upload to GitHub

1. Create a new GitHub repository, for example `mahima-backend-portfolio`.
2. Keep the repository public if you want recruiters to browse the source.
3. Upload these files to the repository root:
   - `index.html`
   - `mahima-profile.png`
   - `Mahima-resume.pdf`
4. Commit the files to `main`.

## Deploy on Vercel

1. Open https://vercel.com and sign in with GitHub.
2. Select **Add New → Project**.
3. Import `mahima-backend-portfolio`.
4. For this static HTML site, no framework setup is required.
5. Click **Deploy**.
6. Vercel will give you a public `.vercel.app` URL.

Once GitHub and Vercel are connected, future pushes to the production branch can trigger new deployments automatically.
